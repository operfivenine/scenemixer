# Системные требования и статус проверки

[← SceneMixer](README.ru.md) · [English](SYSTEM_REQUIREMENTS.md)

Матрица совместимости публичного релиза ещё готовится. Ниже настройки пакета отделены от проверенной работы приложения.

| Пункт | Что известно |
| --- | --- |
| Платформа | Настольная Windows; WIN01 — тестовый пакет x64. |
| Ограничение установщика | В упаковке WIN01 задана Windows 10 build 19045 и новее. Это настройка установщика, а не подтверждение работы на каждой ОС. |
| Проверенные сборки Windows | Матрица тестирования установленного релиза для этой проверки не предоставлена. |
| CPU / ОЗУ / GPU | Минимальные и рекомендуемые значения не установлены. |
| Свободное место | Размер установки и потребности анализа/экспорта здесь не измерены. |
| Компоненты | В материалах WIN01 Python/Qt, медиабиблиотеки, FFmpeg/ffprobe и TransNetV2/ONNX Runtime указаны как встроенные. Состав финального пакета требует релизной проверки. |
| Другие платформы | macOS, Linux, Windows ARM64 и эмуляция не проверены. |

Локальный установщик WIN01 существует, но наличие файла и PE-версия не доказывают успешность установки, воспроизведения и экспорта. Здесь нет заявлений о скорости, расходе памяти, покрытии кодеков или измеренной точности экспорта.
