# Release history / История релизов

## [21.0 R4 · WIN01](https://github.com/operfivenine/scenemixer/releases/tag/v21.0-r4-win01) — 2026-10-18

First public Windows x64 test package, published as a pre-release. Includes the SceneMixer installer and SHA-256 checksum file. No application-code changes were made as part of preparing the GitHub presentation or uploading this installer.

Первый публичный тестовый пакет для Windows x64, опубликованный как предварительный релиз. Доступны установщик SceneMixer и файл контрольных сумм SHA-256. При оформлении GitHub-страницы и загрузке установщика код приложения не изменялся.
