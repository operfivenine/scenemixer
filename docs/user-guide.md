## Settings and built-in help

Use Settings for interface preferences, Export for output settings, and Optional Features for extra tools. Backup settings control copies made before project overwrite; autosave is configured separately in data/project settings. Press F1 to open the searchable bilingual FAQ.

The guides describe 21.0 R4 using its embedded FAQ and WIN01 packaging materials. The linked pages contain written step-by-step instructions. Press F1 for the searchable in-app FAQ.
