# Первый монтаж: автоматический поиск сцен

[← SceneMixer](../../README.ru.md) · [English](01_First_Mix.md)

**Результат:** ролик из выбранных сцен, сохранённый отдельным файлом.

1. Нажмите **«Добавить видео»** или перетащите видео в **область плеера**. Файлы появятся в списке **«Текущий источник»**.
2. Выберите источник для анализа. Настройте **«Чувствительность»**, нажмите **«Определить сцены»** и дождитесь таблицы. Чем выше чувствительность, тем меньшие изменения изображения считаются новой границей.
3. Дважды щёлкните строку сцены или выделите её и нажмите **Enter**, чтобы проверить начало. Отметьте нужные сцены. При необходимости повторите анализ и отбор для других источников.
4. Откройте **Scene Mixer**. Режим **«Полный»** использует весь выбранный набор, **«Выборочный»** — заданную часть. Нажмите **«Смешать Сцены»**.
5. Откройте **Quick Preview**, чтобы проверить порядок и общее впечатление. Это короткий предпросмотр, а не окончательный рендер.
6. Проверьте **«Качество…»**, нажмите **«Экспорт»** и выберите новый итоговый файл. Дождитесь завершения и откройте результат для проверки.
7. Нажмите **Ctrl+S**, чтобы сохранить проект `.smx` для продолжения работы. Сохраните исходные видео на диске.

Если фрагментов слишком много, уменьшите чувствительность и проверьте результат снова. В SCM можно поправить границы или объединить соседние сцены. Для осознанного выбора начала и конца используйте [Cutter](02_Manual_Cutter.ru.md).
