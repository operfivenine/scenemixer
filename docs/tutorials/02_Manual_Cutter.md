# Choose fragments with Cutter

[← SceneMixer](../../README.md) · [Русский](02_Manual_Cutter.ru.md)

**Result:** a set of deliberately chosen scenes, ready for a Mix or a direct Cutter export.

1. Add one or more videos, select a file in **Current source**, and open **Cutter**.
2. Watch the source. Set the selection start and end on the timeline or in the exact controls.
3. Click **Add scene** to keep the range. **Remove last** removes the most recently added scene.
4. Repeat for other ranges and source videos. **Reviewed to here** marks where to continue reviewing a long source; it is a navigation aid.
5. Use **All scenes → Mixer** when selection is complete, then click **Mix Scenes** in Scene Mixer.
6. Check **Quick Preview**, review **Quality…**, and **Export** the finished Mix.

Cutter can also export saved scenes from the current source or all sources directly. Review **Quality…** before starting; the controls for this operation may differ from Mix export.
