# Keyboard shortcuts

[← SceneMixer](../README.md) · [Русский](keyboard-shortcuts.ru.md)

| Action | Shortcut |
| --- | --- |
| Open project | `Ctrl+O` |
| Save project | `Ctrl+S` |
| Save As | `Ctrl+Shift+S` |
| Searchable built-in FAQ | `F1` |
| Play / Pause | `Space` |
| Previous / next frame | `←` / `→` or `,` / `.` |
| Seek to selected scene in scene table | `Enter` |
| Enter / exit fullscreen | `F11` / `Esc` |

These are the defaults documented by the 21.0 R4 FAQ. Playback and scene-table shortcuts depend on the active control; leave text fields before using them.
