# Проекты и SceneMaps

[← SceneMixer](../README.ru.md) · [English](project-files.md)

| Объект | Содержимое | Что учитывать |
| --- | --- | --- |
| Исходное видео | Настоящий медиафайл | Удаление из проекта не удаляет файл с диска. |
| Проект `.smx` | Ссылки на источники, сцены, правки, настройки и состояние Mix | Видео не встроены; их нужно сохранить. |
| Карта `.scm` | Границы сцен и связанные данные источника | Карта относится к источнику; не заменяет проект и не содержит видео. |

## Сохранение, открытие и поиск видео

**Ctrl+S** сохраняет проект, **Ctrl+Shift+S** открывает «Сохранить как…», **Ctrl+O** — существующий проект. При первом сохранении задайте имя. В метаданных проектов 21.0 также указана совместимость со старым `.scenemixer.json`.

Если видео перемещено, откройте **«Проект → Файлы проекта…»**, выделите отсутствующий файл и выберите **«Заменить расположение…»**. Укажите новое место. Если отсутствует несколько файлов, при открытии проекта также может быть предложен поиск в папке.

В **«Настройки → Резервные копии»** включите копии перед перезаписью или создайте копию вручную. Автосохранение настраивается отдельно в разделе данных и проектов. Исходные видео тоже нужно резервировать.

## Редактирование сцен в SCM

SCM работает с уже найденными или сохранёнными сценами: меняет границы, удаляет сцену или объединяет соседние. Предупреждение о границе — повод проверить её в предпросмотре и решить, нужна ли правка.

Обычные изменения сохраняются в `.smx`. Они не переписывают видео и не перезаписывают автоматически существующую карту `.scm`.

## Статусы SceneMaps Library

| Статус | Значение |
| --- | --- |
| Ready | Исправная карта, готова к работе |
| Used / Unused | Используется / сейчас не используется проектом |
| Modified | В связанном проекте есть локальные правки сцен |
| Missing source | Видео не найдено по сохранённому пути |
| Legacy | Старый совместимый формат карты |
| Problem | Ошибка чтения или проверки |
| Exact | Сохранённое число кадров совпало с ожидаемым |

Exact относится к проверке числа кадров и не удостоверяет визуальную точность каждой границы.
