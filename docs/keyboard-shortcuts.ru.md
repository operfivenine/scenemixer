# Горячие клавиши

[← SceneMixer](../README.ru.md) · [English](keyboard-shortcuts.md)

| Действие | Клавиши |
| --- | --- |
| Открыть проект | `Ctrl+O` |
| Сохранить проект | `Ctrl+S` |
| Сохранить как | `Ctrl+Shift+S` |
| Встроенный FAQ с поиском | `F1` |
| Воспроизведение / пауза | `Space` |
| Предыдущий / следующий кадр | `←` / `→` или `,` / `.` |
| Перейти к выбранной сцене в таблице | `Enter` |
| Полноэкранный режим / выход | `F11` / `Esc` |

Это стандартные команды из FAQ 21.0 R4. Клавиши плеера и таблицы зависят от активного элемента; перед их использованием выйдите из текстового поля.
